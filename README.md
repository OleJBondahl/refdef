# refdef

Reference designations (the tags that name things in a plant, a machine or a cabinet) as strict, typed, immutable Python values.
The library has no runtime dependencies and does no file, network, clock or random access.
Every value is a frozen dataclass or an enum.

Status: pre-release, version 0.1.0. The package is an empty scaffold.

## Install

```text
uv add refdef
```

Compatible with IEC conventions.

Documentation: <https://olejbondahl.github.io/refdef/>
